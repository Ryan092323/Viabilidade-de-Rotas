Importe um Excel/CSV, cole dados copiados de uma planilha ou preencha várias linhas de uma só vez.

A planilha precisa ter ROTA, PERFIL, PESO TOTAL e ENTREGAS. O PESO DEVE ESTAR SEMPRE EM KG; o sistema converte automaticamente para Ton. Não é necessário informar o KM: ele será preenchido pela média cadastrada da rota. Colunas KM de planilhas antigas continuam sendo aceitas. Use CARROS para dividir o peso entre os veículos.

Mantenha a primeira linha com os nomes das colunas. O KM não precisa ser incluído: a média da rota será usada automaticamente. Informe o peso sempre em KG; o sistema converte para Ton no resumo.
