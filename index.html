Adicionar várias rotas

Importe um Excel/CSV, cole dados copiados de uma planilha ou preencha várias linhas de uma só vez.

A planilha precisa ter ROTA, PERFIL, PESO TOTAL, KM e ENTREGAS. Use CARROS para dividir o peso entre os veículos e UNIDADE PESO com KG ou TON. Se a linha não tiver unidade, valores como 12.198 serão reconhecidos como Ton (12.198,00 kg); valores no formato 12.198,00 permanecem em kg.

Mantenha a primeira linha com os nomes das colunas. Use KG ou TON na unidade; linhas sem unidade reconhecem automaticamente números com ponto decimal, como 12.198, como Ton.
